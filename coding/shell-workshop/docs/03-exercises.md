## C. 16 道可自动测试的编程题

### 统一契约

- 只编辑 `practice/eNN.sh`，不要调用 `solutions/`、改测试或用 Python 实现题目。
- Bash 3.2+；正常 stdout 是题目规定的数据，诊断写 stderr。除明确透传子命令的题目外，参数错误返回 2，操作失败返回 1。
- 错误文案不要求逐字一致，但应非空且有意义。无额外说明时，不应向 stdout 输出调试日志。
- 输入参数可能有空格、空串、中文、星号、前导 `-`；只有文本题不接受 NUL。涉及文件系统时，父目录可信且不会被恶意并发替换；路径不包含 `.`/`..` 的竞争式改写。
- E13～E15 的任务不会 daemonize、不会产生需要单独管理的后代，并响应 TERM。SIGKILL、掉电、完整进程树管理不在自动验收契约中。
- 每题 `./practice.sh E01` 等独立运行；未完成时 `TODO` 失败是预期。参考答案通过 `./practice.sh solution E01` 调用相同测试。

### E01 · 保留参数边界

**目标：** 理解 `"$@"` 与格式化输出。入口：`e01.sh [ARG...]`，允许零个参数。

输出第一行 `count=N`，后续按 1 开始的下标输出 `i=<参数原文>`，每次打印结束加换行。空参数输出 `i=<>`，星号不展开，参数中的换行保留。成功返回 0。

```text
输入参数：'a b' '' '*.log'
输出：
count=3
1=<a b>
2=<>
3=<*.log>
```

注意：这是展示协议，不是能够无歧义还原任意含换行参数的序列化格式。验收：零参数、空串、空格、换行、中文、前导 `-`、通配符。

### E02 · 环境默认值

**目标：** 区分环境与位置参数。入口无参数，读取 `APP_ENV` 与 `APP_PORT`，未设置或空串分别取 `dev`、`8080`。

输出 `env=VALUE` 和 `port=VALUE` 两行；这里只展示原值，不校验端口类型。多余位置参数返回 2。不要把环境变量重新赋给系统变量 PATH 等。

验收：未设置、空串、自定义值包含空格、多余参数。

### E03 · 十进制整数与范围

入口：`e03.sh N`。只接受 1～3 位 ASCII 数字，转换后范围为 0～255。允许 `008`，必须按十进制解释。打印 `0+1+...+N` 的结果及换行。

`008 → 36`，`255 → 32640`；负数、表达式、超长数字、空串、参数数量不对返回 2，stdout 为空。先限制字符和长度，再做算术。

### E04 · 解析长选项

入口：`e04.sh --name NAME [--times N] [--]`。name 必填且非空；times 默认 1，只接受单字符 1～5；选项顺序任意；同一选项重复出现报错。NAME 允许以 `-` 开头。尾部 `--` 可选，但其后不得有位置参数。

每次输出 `hello=NAME\n`，共 N 次。未知选项、缺值、重复或多余参数返回 2，stdout 为空；必须先完成校验再输出。

### E05 · 保真读行

入口：`e05.sh FILE`。输入为可读普通文本文件；每行打印 `行号:原文\n`。从 1 开始，保留首尾空格、TAB、反斜杠和空行；最后一行无换行也处理。空文件输出为空。

缺文件、目录或不可读文件返回 1；参数数量错误返回 2。文件在读取期间不变化。不要求处理读取中途设备故障或 NUL 二进制。

### E06 · 日志聚合报表

入口：`e06.sh LOG`。忽略空白行与第一个非空白字符是 `#` 的整行注释；其他记录按空白分隔，必须恰好四列：

```text
timestamp level service status
```

timestamp 是非空白不透明标识，不检查日历格式。level 只能是 INFO/WARN/ERROR；service 匹配 `[a-z][a-z0-9_-]*`；status 是 100～599 的三位数字。按 service 聚合总请求数和 status≥500 的数量（不以 level 判断 5xx）。

输出无表头，以 TAB 分隔的 `service\trequests\t5xx\n`，按 C locale 的 service 字节顺序升序排列。空输入成功且输出为空。任何坏行导致返回 1，stdout 为空；缺文件或排序程序失败也返回 1。

样本 `fixtures/access.log` 应输出 `api\t3\t2` 和 `worker\t2\t0`。提示：awk 先聚合，在 END 判断是否整体有效再输出。

### E07 · NUL 文件清单

入口：`e07.sh DIRECTORY`。递归列出后缀为 `.log` 的普通文件，包含点文件，不跟随目录或文件符号链接；根目录本身是符号链接则拒绝，返回 1。

每个路径后输出 NUL，不是换行，顺序不限。绝对根路径保留为绝对路径；相对根路径前加 `./` 后交给 find，例如 `-logs` 输出 `./-logs/x.log\0`。空目录无输出且成功。不存在或非目录返回 1。

验收包含换行、空格、星号和前导 `-` 文件名。不要用变量捕获整个清单，也不要用 `ls` 解析。

### E08 · dry-run 与执行

入口：`e08.sh --dry-run|--run -- COMMAND [ARG...]`。必须有分隔符和命令。

dry-run：对 COMMAND 和每个参数逐项用 Bash 的 `%q` 输出，一项一行，不执行。run：原样执行命令并透传 stdout、stderr、退出码。命令不存在/不可执行遵守 Bash 常规 127/126 状态。错误模式或缺参数返回 2。

验收：dry-run 不创建文件、空参数保留、星号不展开、命令返回 7 时包装器也返回 7。不得使用 eval 或 `bash -c "$拼接字符串"`。

### E09 · 解析配置数据

入口：`e09.sh CONFIG`。格式为 LF 文本，拒绝 CR。忽略真正的空行和首字符为 `#` 的注释；其余行必须含 `=`，以第一个 `=` 分割键值，不去空格、不执行转义/引号/变量/命令替换。

只允许 APP_NAME 和 PORT，必须各出现一次。APP_NAME 任意非空行内文本；PORT 为 1～5 位 ASCII 数字，十进制 1～65535，允许前导零。未知键、重复键、缺键、非法格式返回 2；文件不可读返回 1。

完整成功后输出 `name=原文\nport=十进制数\n`。错误时 stdout 为空。`APP_NAME=$(touch pwned)=literal` 必须保持原文，不能创建文件。

### E10 · 原子写文件

入口：`e10.sh TARGET < INPUT`。TARGET 非空，父目录已存在；允许不存在或已有普通文件，拒绝目录和任何符号链接（含断链）。支持二进制 stdin，成功时 stdout 为空。

在同一父目录创建随机临时文件，以 0600 权限写入；写入成功才替换 TARGET。cat 或 mv 失败返回 1、保留旧目标，并清理临时文件。参数错误返回 2。

约定：单写者、本地可信父目录、目标类型在执行期间不变；无需保留旧元数据，不承诺 fsync/断电持久性。上游提前失败但正常关闭流的问题由调用方负责：本题不能从 EOF 推断上游业务是否成功。

### E11 · 不覆盖的备份归档

入口：`e11.sh SOURCE_DIR NEW_ARCHIVE`，两个参数必须是绝对路径。源必须为真实目录，不能是根 `/` 或目录符号链接；归档父目录已存在，归档不能位于源内部（包括父路径经符号链接指回源目录）。不覆盖已有文件或符号链接。

把源内容以相对路径归档为 tar.gz，包含隐藏文件与子目录。先写同归档目录的临时文件，tar 创建和列表检查均成功后发布；最终不残留临时文件。stdout 为空。

非绝对路径、源为 `/`、归档位于源内部返回 2；源/父目录不可用、目标已存在、tar/发布失败返回 1。父目录可信、目标不会在发布时被替换成目录；可用同目录硬链接实现“存在就失败”的发布。源在备份期间不修改，不跟随源内部的符号链接去归档外部内容。

验收会读取归档核对内容，还会注入 tar 失败。进一步自行做一次恢复后比对。

### E12 · 有限重试

入口：`e12.sh ATTEMPTS DELAY -- COMMAND [ARG...]`。ATTEMPTS 为单字符 1～5，DELAY 为单字符 0～2，单位秒。缺少命令等参数问题返回 2。

第一次立即运行；成功立即返回 0；失败且仍有次数才等待 DELAY 秒；全部失败时返回最后一次命令状态。每次子命令的输出原样透传；重试提示写 stderr，不能额外执行第 N+1 次。

验收：第三次成功时立刻停止、全部失败保留 7、带空格的命令路径、非法次数。单次超时、信号转发和是否幂等由调用者/扩展负责，本题不实现错误分类或输出回滚。

### E13 · 临时目录与清理

入口：`e13.sh -- COMMAND [ARG...]`。通过 `mktemp -d` 在 `${TMPDIR:-/tmp}` 下创建独有的 `shell-workspace.*` 目录，以环境变量 WORK_DIR 提供给命令；目录默认仅当前用户可访问。

正常结束透传命令状态，先清理目录再退出；接收 TERM 时向直接子进程发送 TERM、wait 回收、清理目录，最终返回 143。INT 可按同一思路返回 130（自动测试实际验证 TERM）。保留子命令 stdin、stdout、stderr。

只删除自己刚创建的目录，不接受外部删除目标。直接子进程须响应 TERM 且不产生需要单独管理的后代；无法捕获 SIGKILL。参数错误返回 2。

### E14 · 目录互斥锁

入口：`e14.sh LOCK_DIR -- COMMAND [ARG...]`。锁路径非空，父目录已存在。原子尝试创建目录；获取失败统一返回 75，打印诊断，不运行命令，不删除或更改已有锁。

获取成功才安装清理逻辑；正常结束返回子命令状态并删除自己创建的空锁目录。TERM 时通知直接子进程并 wait，然后释放锁、返回 143。INT 类似返回 130（自动测试验证 TERM）。子命令不得修改锁目录内容或 daemonize。

验收：争用时第二个任务不执行；第一个任务被 TERM 停止后可以重新获取；子命令失败也释放；已有锁中的文件保持原样。不实现自动处理陈旧锁。

### E15 · 有界并发批处理

入口：`e15.sh LIMIT EXECUTABLE -- [ITEM...]`。LIMIT 为单字符 1～4；EXECUTABLE 是实际可执行文件路径（不在 PATH 中猜测命令），每个任务调用一次 `EXECUTABLE "$item"`，stdin 使用 `/dev/null`。

任意时刻运行的任务不超过 LIMIT；有至少两个任务且 LIMIT≥2 时必须实际并发。每项恰好处理一次；某项失败仍处理余下全部任务；所有子进程都 wait 后返回，全成功为 0，任一失败为 1。允许零项。输出顺序不保证。

TERM 时不再启动下一项，通知当前直接子进程并回收，返回 143；INT 类似返回 130（自动测试验证 TERM）。兼容 Bash 3.2，不得依赖 wait -n。允许分批并发，不要求动态补位。无效上限/worker/参数返回 2。

### E16 · 正确处理管道状态

入口：`e16.sh LITERAL FILE`。按字面字符串筛选包含 LITERAL 的文本行，C locale 排序去重，输出完整行。空 LITERAL 合法，会匹配所有行。无匹配返回 0、输出为空。

必须使用 grep 与 sort 组成的管道，并检查两阶段状态：grep 的 0/1 是正常，其他状态是操作失败；sort 非 0 也失败，整体返回 1。缺文件返回 1，参数数量错误返回 2。不能用无条件 `|| true` 吞掉错误。

本题失败时不承诺撤回已经输出的部分数据；需要事务式输出时，在外层使用临时产物与发布阶段。

## D. 3 个综合项目

这些项目没有预写的整套实现或自动评分，需求和验收清单是你的实施依据。放在 `scratch/p01` 等独立目录中，先用本地样本，不连接真实生产服务。

### P01 · 日志日报命令（2～3 小时）

目标接口：`report.sh --input LOG --output REPORT [--service NAME]`。

将 E04/E06/E10 组合起来：先完整校验并统计，再按服务过滤，输出带表头 TSV；额外计算两位小数的 5xx 比例。输入完全无记录时仅输出表头；筛选服务不存在也仅输出表头。坏行、依赖失败、输出失败分别有清楚诊断和非零状态。

验收：① 样本 api 为 3 次请求、2 次 5xx、66.67%；② 重复执行结果一致；③ 输入损坏时原报表不变；④ 路径包含空格；⑤ 无匹配服务；⑥ 临时文件无残留。不要先写表头覆盖目标，再发现后面统计失败。

加分：增加输入行数/坏行统计的宽松模式，但不能让宽松模式改变默认严格语义。

### P02 · 本地备份管家（3～4 小时）

目标接口：`backup.sh --source DIR --dest DIR --name NAME`，以及 `restore-check.sh ARCHIVE`。先约定 NAME 仅由字母、数字、下划线、连字符组成；源和备份目录不得互相嵌套；不跟随目录符号链接。

组合 E11/E14：同一目标上的任务互斥，备份失败不发布，已有归档不覆盖；记录备份名字、时间、文件数和校验结果。restore-check 只恢复自己生成的可信归档到新建临时目录，再与已知样本比对。目录可能变化的真实数据源不在首版支持范围内。

验收：① 隐藏文件与空目录；② 文件内容含 NUL；③ 已有备份保持原样；④ tar 失败无半成品；⑤ 同时启动两次只有一个拥有锁；⑥ 恢复验证有明确成功/失败；⑦ 不能把归档放进源目录。

加分：增加保留策略的 **dry-run**，明确按完成时间还是名字排序、只处理本工具创建的归档、保留数量不足时不操作。实际删除需另设明确命令，不与正常备份隐式混在一起。

### P03 · 本地任务批处理器（3～5 小时）

目标接口：`batch.sh --jobs N --attempts M --items FILE --worker EXECUTABLE --output REPORT`。items 是一行一个不含换行的任务 ID；不忽略空行，空行代表空 ID。每项顺序编号，即使两个 ID 相同也视为两个独立任务。

组合 E05/E12/E13/E15：有限并发、每项有限重试、每项独立工作目录与结果文件，最后按输入编号输出汇总。成功返回 0，存在失败返回 1，参数错误返回 2，中断返回 143。明确定义中断时未开始/进行中/已完成任务怎样记录。

验收：① 带空格 ID 不拆开；② 至少两个任务真正并发；③ 峰值不超过 N；④ 故意失败两次后成功的任务尝试次数正确；⑤ 永远失败的任务不会无限循环；⑥ 汇总顺序稳定，子任务日志不混进结果；⑦ TERM 后回收直接子进程与临时目录；⑧ 不要求保留失败尝试输出作为最终成功结果。

加分：做 N=1、2、4 的对比实验，报告任务耗时分布与资源限制，并解释为什么分批策略可能有空闲槽位。
