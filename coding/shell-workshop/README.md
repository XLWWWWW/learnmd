# Shell 编程：教程 + 练习 + 工作场景

这是一套中文、可以边改边测的 Shell 学习工程。目标是让你能读懂日常脚本，独立编写文件处理、日志分析、备份、重试和批量任务，并能解释脚本在输入异常、命令失败、并发和中断时的行为。

**共 51 道主任务：24 道理解题、8 道排错题、16 道自动测试编程题、3 个综合项目。** 每道编程题都有独立的练习文件、分层提示和参考实现；测试对练习和答案使用同一份输入输出契约。综合项目提供需求、验收标准和参考设计，留给你自己组合实现。

## 先开始第一轮

在终端运行：

```bash
cd /Users/xlwwwww/learnmd/coding/shell-workshop
./practice.sh doctor
./practice.sh demo basic
./practice.sh E01
```

最后一条初始会失败，并显示 `TODO E01`：这是待实现练习的预期状态，不是环境坏了。打开 [practice/e01.sh](practice/e01.sh)，按照 [E01 题目](docs/03-exercises.md#e01--保留参数边界) 实现，再运行同一条命令。

`demo basic` 的预期输出：

```text
count=3
1=<hello shell>
2=<>
3=<*.log>
```

读懂这三个参数为什么不能被拆开，是后面处理路径、命令和配置的基础。

## 环境与边界

- 主线是 **Bash 3.2+**，兼容本机 `/bin/bash`；Bash 4/5 的功能在文档中单独标记。终端默认使用 zsh 不影响 `./practice.sh` 按 shebang 使用 Bash。
- 面向 macOS 与常见 Linux，使用 Bash、awk、grep、sort、find、mktemp、tar 等常用工具。不假定所有 Unix、BusyBox 或 `/bin/sh` 都能直接运行。
- **自动测试需要 Python 3.8+，只用标准库。习题实现全部是 Shell。** 直接运行单个脚本和演示不需要 Python。
- ShellCheck 是可选静态检查工具；没有安装时会明确跳过。工程不会自动安装软件、联网访问服务、创建定时任务或修改系统配置。
- 涉及写文件的练习只操作传入的测试路径；测试在自己的临时目录中运行。综合项目建议放在被 Git 忽略的 `scratch/` 下。
- 这是本地可信目录下的教学脚本。并发修改目录、网络文件系统、不可中断子进程、完整进程树管理等边界见各题和教程。

## 练习命令

```bash
./practice.sh E05               # 只测自己的第 5 题
./practice.sh all               # 测自己的全部 16 题，未做完的题会失败
./practice.sh solution E05      # 只验证第 5 题参考实现
./practice.sh solution          # 验证全部参考实现
./practice.sh check             # Bash 语法检查 + 可选 ShellCheck
./practice.sh demo logs         # 日志报表
./practice.sh demo config       # 安全读取配置数据
./practice.sh demo backup       # 临时数据备份、恢复、比对，然后清理
```

参考实现只在显式选择 `solution` 或演示时运行，不会覆盖你的练习。**`solution` 全绿不能证明你的 `practice/` 已完成。** `check` 也只是语法与静态检查，不能代替行为测试。

默认测试解释器是 `/bin/bash`。如果你另有 Bash，可明确选择其路径：

```bash
BASH_BIN=/你的/bash/绝对路径 ./practice.sh solution
```

本项目不依赖当前工作目录；也可以从别处使用 `bash /绝对路径/shell-workshop/practice.sh E01` 启动。

## 建议的 12 次学习安排

每次 45～75 分钟。比起一次看完，更推荐隔天不看答案重做。

| 次数 | 阅读与题目 | 完成标准 |
|---|---|---|
| 1 | 教程 1～5；Q01～Q04；E01、E02 | 解释一条命令实际收到哪些参数 |
| 2 | 教程 6～8；Q05～Q08；E03、E04 | 校验输入，正确解析选项和退出码 |
| 3 | 教程 9～11；Q09～Q12；E05 | 正确读到空行与最后一行 |
| 4 | 教程 12～13；Q13～Q15；E06、E07 | 区分文本记录和文件名记录 |
| 5 | 教程 14～16；Q16～Q18；E08、E09 | 不用字符串拼接执行命令，不执行配置内容 |
| 6 | 场景 1～6；D01～D04；E10 | 文件更新失败后保留原文件 |
| 7 | 场景 7～10；E11、E12 | 验证备份恢复，限制重试次数 |
| 8 | 教程 17～19；Q19～Q24；E13、E14 | 说明资源归谁创建、由谁清理 |
| 9 | 场景 11～16；D05～D08；E15、E16 | 证明并发有上限、失败不会被吞掉 |
| 10 | P01 日志日报；重做 E05/E06 | 将数据输入、计算和输出组合成命令 |
| 11 | P02 备份管家或 P03 批处理器 | 给工具定义退出码、失败和恢复策略 |
| 12 | 工作检查表；不看答案重做 E10/E14/E16 | 能向同事解释脚本的正确性与边界 |

推荐每道题记录四件事：**我预测的行为、实际结果、错因、工作中会在哪里遇到。** 通过后再主动加一个新用例，例如空串、中文、路径里有空格、命令失败或 TERM 中断。
