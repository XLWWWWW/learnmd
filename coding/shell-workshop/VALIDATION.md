## 行为测试覆盖

- 参数：零参数、空串、中文、空格、换行、星号、前导 `-`、选项重复与缺值。
- 文本：空文件、空行、首尾空格、反斜杠、无末尾换行、错误日志行、配置中的命令替换字面量。
- 文件：NUL 分隔清单、文件名含换行、隐藏文件、不跟随符号链接、根符号链接末尾带 `/`。
- 写入：二进制数据、0600 权限、已有目标、目录/符号链接拒绝、模拟 cat 写出部分数据后失败而旧目标不变。
- 备份：读取归档核对二进制与隐藏文件、空目录、拒绝覆盖、拒绝嵌套目标、通过符号链接父路径指回源目录、模拟 tar 失败不发布。
- 重试：指定次数后成功立即停止、全部失败返回最后状态、次数校验。
- 生命周期：临时目录成功/失败后清理、stdin 保留、TERM 后回收直接子进程并清理。
- 锁：第二个任务不执行、不删除其他持有者的锁；结束或 TERM 后释放；锁内已有文件不被修改。
- 并发：共享计数器验证上限与每项恰好一次；双任务屏障验证确实同时运行；混合成功/失败仍回收全部；TERM 后直接子进程被回收。
- 管道：无匹配成功、字面符号不当作正则、模拟 grep 与 sort 失败时返回非零。

测试使用自己的临时目录、进程组和每次运行的超时；不会联网或操作真实服务。命令故障通过临时 PATH 中的假程序注入，不替换系统程序。

## 验证范围限制

- 尚未在 Linux、Bash 4/5、其他 CPU/文件系统上运行。设计避免了常见 GNU/BSD 差异，但实际部署平台仍需执行测试。
- 没有声称覆盖所有执行路径。INT 的处理代码已提供，自动信号测试实际使用 TERM；SIGKILL 不可能触发正常 trap 清理。
- 不验证不可信目录中的竞争式路径替换、网络文件系统锁语义、断电持久性、完整进程树或忽略 TERM 的任务。
- 参考脚本的适用约定见题册：例如 E10 的单写者/可信父目录、E11 的静态源目录、E13～E15 的直接子进程限制。
- 3 个综合项目是开放练习，提供需求与参考设计，没有冒充已实现或已自动验收的产品。

本工程没有改动已有 Go 教程，也没有安装依赖、配置 cron、提交 Git 或修改系统配置。
